# เว็บสวัสดีวันศุกร์ 💗

เว็บนี้เป็นเว็บหน้าเดียวแบบตอบคำถาม รองรับมือถือ คอมพิวเตอร์ และแท็บเล็ต พร้อมนำขึ้น GitHub Pages ได้ทันที

## ไฟล์สำคัญ

- `index.html` เนื้อหาและโครงหน้าเว็บ
- `styles.css` สี รูปแบบ และแอนิเมชัน
- `script.js` การกดปุ่ม การเปลี่ยนหน้า และคำตอบ
- `assets/sad-cat.png` รูปแมวสำหรับคำตอบ “ไม่คิดถึง”

## ทดลองเปิดในเครื่อง

ดับเบิลคลิกไฟล์ `index.html` หรือเปิดโฟลเดอร์ใน Visual Studio Code แล้วใช้ Live Server

## ทำเป็นลิงก์ด้วย GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub เช่น `friday-message`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ โดยให้ `index.html` อยู่ที่หน้าแรกของ Repository
3. ไปที่ `Settings` > `Pages`
4. ที่หัวข้อ `Build and deployment` เลือก `Deploy from a branch`
5. เลือก Branch `main` และ Folder `/ (root)` แล้วกด `Save`
6. GitHub จะแสดงลิงก์รูปแบบ `https://ชื่อผู้ใช้.github.io/friday-message/`

## จุดที่แก้ข้อความได้ง่าย

ค้นหาข้อความที่ต้องการใน `index.html` เช่น

- `สวัสดีวันศุกร์`
- `วันนี้ทำงานเหนื่อยไหมมม`
- `คิดถึงเค้ามั้ยยย`
- `จุ๊บหนึ่งทีค้าบบบ`

ข้อความผลลัพธ์หลังตอบอยู่ใน `script.js`
